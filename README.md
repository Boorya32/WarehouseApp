# Учет товаров на складе (WarehouseApp)

**ФИО:** Уручьева Ксения Витальевна 
**Группа:** 9ИС-445  
**Стиль кода:** Google C++ Style Guide  

## Цель и задача 
Создать консольное приложение для автоматизации учета товаров.

## Технические требования
- Язык: C++17
- Хранение: `std::vector`
- Формат файла: TXT 
- Обработка ошибок ввода: реализована 

## Структура проекта
- **src/** — исходный код программы
  - `main.cpp` — точка входа
  - `Product.h` — класс товара
  - `Warehouse.h` / `Warehouse.cpp` — логика склада, CRUD, аналитика
  - `FileIO.h` / `FileIO.cpp` — чтение и запись файлов
  - `Menu.h` / `Menu.cpp` — консольный интерфейс
- **data/** — папка с данными
  - `products.txt` — файл с товарами
- **screenshots/** — скриншоты работы программы
- `README.md` — этот файл (лол)
